## 📖 О проекте

**JSON Flattener** --- это гибкое Java-приложение для обработки глубоко
вложенных JSON. Оно позволяет превращать сложные структуры в плоские,
удобные для анализа, интеграции или обработки в ETL-пайплайнах.

Подходит для:

-   **🔧 Разработчиков** --- работающих с тяжёлыми JSON API\
-   **📊 Аналитиков данных** --- подготавливающих JSON к анализу\
-   **🔗 Интеграторов** --- работающих с системами обмена данными\
-   **🎓 Студентов** --- изучающих обработку JSON и CI/CD

------------------------------------------------------------------------

## ✨ Особенности

### 🎯 Основной функционал

-   **📊 Плоское представление JSON** --- вложенные ключи превращаются в
    `key.subkey.subsubkey`
-   **🔍 Поиск по составным ключам** (например: `user.address.city`)
-   **🎯 Фильтрация массивов** по заданным условиям
-   **⚙️ Гибкая конфигурация** --- properties-файлы, переменные
    окружения

### 🛠 Технологии и качество

-   **✅ Тестовое покрытие 75%+** (JaCoCo)
-   **📝 Проверка стиля** (Checkstyle)

-   **📚 JavaDoc** --- полная документация классов и методов

## 📦 Установка и запуск

### Windows (PowerShell / CMD)

``` cmd
:: 1. Клонируйте репозиторий
git clone https://github.com/Mori2282/Json-Flattener.git

:: 2. Перейдите в директорию проекта
cd Json-Flattener

:: 3. Соберите проект
gradlew.bat build

:: 4. Подготовьте входные данные
copy data\input.json data\my-data.json

:: 5. Запустите приложение
set INPUT_JSON=data\my-data.json
gradlew.bat runApp

:: 6. Запустите тесты
gradlew.bat test
```

### Linux / macOS

``` bash
# 1. Клонируйте репозиторий
git clone https://github.com/Mori2282/Json-Flattener.git

# 2. Перейдите в директорию проекта
cd Json-Flattener

# 3. Соберите проект
./gradlew build

# 4. Подготовьте входные данные
cp data/input.json data/my-data.json

# 5. Запустите приложение
export INPUT_JSON=data/my-data.json
./gradlew runApp

# 6. Запустите тесты
./gradlew test
```
